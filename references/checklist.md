# 交付参数与自检清单

## 参数（一票否决项加粗）

| 项 | 要求 | 检测方法 |
|---|---|---|
| 容器/编码 | MP4 / H.264 High | ffprobe |
| 视频码率 | ≥18 Mbps，建议 30 | **注意：是白模和对比都要满足，原片自身不满足也要指出** |
| 音频 | AAC 立体声，≥44.1kHz，**≥320kbps** | `-c:a aac_at` 才上得去 |
| 画面 | **短边 ≥1080** | 2160×1080、1080×2160 都行；1920×1080 也过 |
| 帧率 | ≥24，整数 | 和原片一致 |
| 时长 | 5–60 秒 | |
| 音轨 | 白模和对比**都必须有** | |
| 包结构 | `ID.zip → ID/{4 个同名文件}` | **不得有子文件夹、不得有 `.blend1`** |

## 自检脚本该覆盖的项

1. 四个文件都在，名字对得上 ID
2. 每个视频的编码 / 码率 / 分辨率 / 帧率 / 时长
3. 音频编码 / 采样率 / 声道 / 码率，以及**是否真有音轨**
4. 白模与对比的**总帧数一致**
5. 对比视频的**上半原片、下半白模分割线位置正确**
6. 切点帧位置（白模与原片在同一帧切）
7. 首帧非黑、**片尾非黑**（片尾黑帧检查要用 `-loglevel info` 取 signalstats，用 `-v error` 取不到数据会静默跳过）
8. `.blend` 能打开，场景数、帧范围、分辨率、帧率正确
9. 包内多余文件（`.blend1` 是最常见的一个）

**原片自身不达标要在报告里单独说明**，不要混进"我做的部分不合格"里。

## 调色

```
curves=all='0/0.075 0.36/0.325 0.51/0.59 0.80/0.85 1/1',eq=saturation=1.5
```

目标（对标样板片）：亮度中位 ≈83、最暗 ≈20、饱和 ≈59。
含义：暗部抬起来不压死黑、中间调压下来、高光保住、饱和提上去。**白模不跟原片调色** —— 原片暗，白模要亮，因为验收看的是结构清不清楚。

## 音频编码

```bash
-c:a aac_at -b:a 320k -ar 48000 -ac 2
```

`aac_at` 是 macOS AudioToolbox。ffmpeg 自带的 `aac` 在语音上给多高都只到 ~175kbps。
